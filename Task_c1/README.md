# Task_c1

Строит все строки длины N из заданного алфавита без одинаковых соседних символов.

## Функциональность

- Алфавит передаётся списком односимвольных строк, длина целым неотрицательным числом.
- Повторяющиеся буквы алфавита не дублируют результат.
- При N = 0 результат содержит пустую строку; для пустого алфавита и N > 0 результатов нет.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_c1`. При первом запуске Gradle скачает зависимости.

```bash
./gradlew run
```

Для алфавита `("a" "b" "c")` и N = 2 получаем `[ab ac ba bc ca cb]`.

## Стек

Clojure 1.12.0 на Java 21; самостоятельный проект со своим Gradle Wrapper, тесты через `clojure.test`.

## Проверка

```bash
./gradlew check
```

Проверяются пример задания, нулевая длина, пустой и односимвольный алфавит, повтор букв, количество вариантов и отсутствие одинаковых соседей.
