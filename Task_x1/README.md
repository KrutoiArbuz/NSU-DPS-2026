# Task_x1

Объединяет частичные записи людей из исходного XML и записывает один полный профиль на каждый ID.

## Функциональность

- Читает разные формы имён, пола и родственных ссылок через SAX.
- Нормализует пробелы и восстанавливает обратные связи родителей, детей, супругов, братьев и сестёр.
- Проверяет корневое количество людей, количества детей и братьев/сестёр.
- Разделяет людей с одинаковым полным именем по ID и согласованным сведениям.
- Записывает структурированный XML через StAX, уточняя роли `father`, `mother`, `brother`, `sister`, `son`, `daughter`.

## Запуск

Нужна Java 21. Все команды выполняются из папки `Task_x1`. Положите архив `task_X1.zip` из задания рядом с `build.gradle`. Результаты записываются в `build`.

```bash
./gradlew run
```

Результат: `build/people.xml`.

```bash
./gradlew run --args='--input task_X1.zip --output build/custom.xml'
```

### Флаги

| Флаг | Значение |
| --- | --- |
| `--input` | Путь к исходному ZIP с `people.xml` либо к распакованному XML; по умолчанию `task_X1.zip` |
| `--output` | Путь к нормализованному XML |

По умолчанию `--output` равен `build/people.xml`. Повторный запуск перезаписывает выбранный файл результата.

## Стек

Java 21, SAX и StAX из JDK, Gradle Wrapper, JUnit Jupiter 5.9.1.

## Проверка

```bash
./gradlew check
```

Тесты проверяют разные формы полей, объединение записей, обратные связи, тёзок, ошибочные количества, неизвестную ссылку и чтение ZIP.
