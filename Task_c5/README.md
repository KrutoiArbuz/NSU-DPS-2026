# Task_c5

Обедающие философы используют STM: каждая вилка хранит владельца и счётчик использований в ref.

## Функциональность

- Обе вилки берутся одной транзакцией, частичного захвата нет.
- Настраиваются количество философов, длительности размышления и еды, число приёмов пищи.
- Выводятся время, состояние вилок и количество внутренних перезапусков транзакций.
- Отдельный ограниченный опыт воспроизводит livelock намеренно неудачного раздельного захвата.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_c5`. При первом запуске Gradle скачает зависимости.

```bash
./gradlew run
```

Без аргументов сравниваются четыре и пять философов: размышление 20 мс, еда 20 мс, десять приёмов пищи. После каждого запуска печатается отдельный пример livelock на пять раундов.

Свои параметры:

```bash
./gradlew run -PappArgs='5 10 20 8'
```

| Аргумент по порядку | Значение |
| --- | --- |
| `5` | Число философов, не меньше двух |
| `10` | Размышление в миллисекундах |
| `20` | Еда в миллисекундах |
| `8` | Число приёмов пищи каждого философа |

С выбранными параметрами запускается обычный алгоритм. Пример livelock показывает режим без аргументов.

## Стек

Clojure 1.12.0 на Java 21; самостоятельный проект со своим Gradle Wrapper, тесты через `clojure.test`.

## Проверка

```bash
./gradlew check
```

Проверяются отсутствие частичного захвата, завершение для двух, четырёх и пяти философов, счётчики вилок, освобождение после еды и отсутствие прогресса в ограниченном примере livelock.
