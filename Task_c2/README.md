# Task_c2

Ленивая бесконечная последовательность простых чисел, построенная решетом Эратосфена.

## Функциональность

- Значение `primes` выдаёт простые числа без заранее заданной верхней границы.
- Вызов `prime-numbers` создаёт независимую последовательность.
- Арифметика поддерживает большие целые числа.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_c2`. При первом запуске Gradle скачает зависимости.

```bash
./gradlew run
```

Печатаются первые 25 простых чисел, начиная с `2 3 5 7 11`.

## Стек

Clojure 1.12.0 на Java 21; самостоятельный проект со своим Gradle Wrapper, тесты через `clojure.test`.

## Проверка

```bash
./gradlew check
```

Проверяются первые простые числа, тысячное простое 7919 и все простые меньше 1000 сравнением с независимой проверкой делителей.
