# Task_x3

XSLT выбирает человека с обоими родителями, известным предком второго поколения и братьями или сёстрами, затем создаёт HTML его семейного круга.

## Функциональность

- Выводит карточки выбранного человека, его отца, матери, братьев и сестёр.
- Для каждой карточки показывает имя, пол, родителей, братьев/сестёр, сыновей/дочерей, бабушек/дедушек, дядей/тётей.
- Показывает «нет сведений» для неизвестной группы родственников.
- Если подходящего человека нет, сообщает об этом на странице.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_x3`. Сохраните XML, полученный в Task_x2, в файл `people.xml` рядом с `build.gradle`:

```bash
./gradlew run
```

Откройте `build/family.html` в браузере.

Другие пути:

```bash
./gradlew run --args='--input people.xml --output build/custom.html'
```

### Флаги

| Флаг | Значение |
| --- | --- |
| `--input` | Нормализованный XML, по умолчанию `people.xml` |
| `--output` | HTML-результат, по умолчанию `build/family.html` |

Исходный архив с частичными записями сначала должен пройти X2. Повторный запуск перезаписывает выбранный HTML.

## Стек

Java 21, DOM с XML Schema, XSLT 1.0 из JDK, Gradle Wrapper, JUnit Jupiter 5.9.1.

## Проверка

```bash
./gradlew check
```

На маленькой семье тест проверяет четыре карточки, пол и все требуемые родственные имена именно в карточке выбранного человека. Другой тест проверяет сообщение при отсутствии подходящей семьи.
