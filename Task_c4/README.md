# Task_c4

Моделирует производство часов и сейфов при ограниченном запасе руды.

## Функциональность

- Склад хранит запас в atom с валидатором, сообщения поставок обрабатывает agent.
- Фабрика забирает доступную часть ингредиента и сохраняет её до полного сбора рецепта.
- После сбора ингредиентов ждёт время производства, передаёт готовый товар и возвращает новое состояние.
- Исходные рецепты и обычные задержки сохранены; источники останавливаются через interrupt.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_c4`. При первом запуске Gradle скачает зависимости.

```bash
./gradlew run
```

По умолчанию источники работают 45 секунд. Затем программа завершает начатые циклы и выводит количество произведённых сейфов и часов.

Другой срок работы источников:

```bash
./gradlew run -PappArgs='60'
```

Один позиционный аргумент задаёт секунды добычи. Для появления сейфа нужно накопить металл, поэтому слишком короткий запуск может ещё не дать оба вида изделий.

## Стек

Clojure 1.12.0 на Java 21; самостоятельный проект со своим Gradle Wrapper, тесты через `clojure.test`.

## Проверка

```bash
./gradlew check
```

Проверяются сбор рецепта из двух частичных поставок, конкурентное изъятие запаса без отрицательных значений и выпуск обоих конечных товаров. Производство в тестах ускорено, рецепты сохраняются.
