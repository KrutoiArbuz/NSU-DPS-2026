# Task_j1

TCP-сервер выдаёт клиенту пару ключей RSA-8192 и подписанный сертификат X.509.

## Функциональность

- Клиент сохраняет приватный ключ в `.key`, сертификат в `.crt`.
- Повторный запрос с тем же именем получает тот же результат из кеша.
- Можно задержать чтение ответа или отключить клиента через `--abort`.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_j1`. При первом запуске Gradle скачает зависимости.

1. Создать ключ подписи сервера:

```bash
./gradlew signingKey --args='--output issuer.key'
```

2. Запустить сервер и оставить терминал открытым:

```bash
./gradlew run --args='--host 127.0.0.1 --port 8080 --workers 2 --signing-key issuer.key --issuer "CN=NSU"'
```

3. В другом терминале из той же папки запустить клиента:

```bash
./gradlew client --args='--host 127.0.0.1 --port 8080 --name Alice --output alice'
```

Ожидаются файлы `alice.key` и `alice.crt`. Генерация RSA-8192 занимает время. Сервер останавливается через Ctrl+C. Существующие ключи и сертификаты не перезаписываются: для следующего запуска задавайте новый `--output`.

### Флаги сервера

| Флаг            | Что задаёт                                                |
| --------------- | --------------------------------------------------------- |
| `--host`        | Адрес прослушивания, по умолчанию `0.0.0.0`               |
| `--port`        | Порт, по умолчанию `8080`                                 |
| `--workers`     | Число потоков генерации; обязательное положительное число |
| `--signing-key` | Путь к ключу подписи; обязателен                          |
| `--issuer`      | Имя издателя, например `CN=NSU`; обязательно              |

### Флаги клиента

| Флаг       | Что задаёт                                                          |
| ---------- | ------------------------------------------------------------------- |
| `--host`   | Адрес сервера; обязателен                                           |
| `--port`   | Порт сервера; обязателен                                            |
| `--name`   | Имя клиента в ASCII без нулевого байта; обязательно                 |
| `--output` | Префикс файлов `.key` и `.crt`, по умолчанию `client`               |
| `--delay`  | Задержка перед чтением ответа в секундах, по умолчанию `0`          |
| `--abort`  | Закрыть соединение без чтения ответа; значение после флага не нужно |

У `signingKey` один флаг: `--output`, по умолчанию `issuer.key`.

## Проверка

```bash
./check.sh
```

Скрипт запускает все тесты и собирает приложение. Проверяются протокол, кеш, очередь генерации, 100 соединений, отключения клиентов, RSA-8192 и сохранение файлов.

### Ручная проверка

```bash
./gradlew client --args='--host 127.0.0.1 --port 8080 --name Alice --output alice-repeat'
cmp alice.key alice-repeat.key
cmp alice.crt alice-repeat.crt
```

Проверка задержки перед чтением:

```bash
./gradlew client --args='--host 127.0.0.1 --port 8080 --name Alice --output alice-delay --delay 3'
```

Клиент ждёт три секунды перед чтением и затем сохраняет файлы.

Проверка отключения и повторного запроса:

```bash
./gradlew client --args='--host 127.0.0.1 --port 8080 --name Bob --delay 1 --abort'
./gradlew client --args='--host 127.0.0.1 --port 8080 --name Bob --output bob'
```

Первый клиент пишет `Disconnected without reading the response` и не создаёт файлы. Второй получает результат; сервер продолжает работать.

Имя клиента и издателя сертификата:

```bash
openssl x509 -in alice.crt -noout -subject -issuer
```

В выводе должны быть `Alice` и `NSU`.
