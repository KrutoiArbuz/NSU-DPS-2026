# Task_x2

Расширяет X1: записывает нормализованные профили через JAXB и проверяет их по строгой XML Schema.

## Функциональность

- Содержит собственные исходники чтения и модели, перенесённые из X1.
- JAXB сериализует уникальные ID и объектные ссылки IDREF.
- Схема требует порядок полей, непустые имена, известные обозначения пола и неотрицательные количества.
- Неизвестные элементы, повтор ID и ссылка на отсутствующий ID отвергаются.

## Запуск

Нужна Java 21. Все команды выполняются из папки `Task_x2`. Положите архив `task_X1.zip` из задания рядом с `build.gradle`. Результаты записываются в `build`.

```bash
./gradlew run
```

Результат: `build/people.xml`. X1 отдельно запускать не требуется.

```bash
./gradlew run --args='--input task_X1.zip --output build/custom.xml'
```

### Флаги

| Флаг | Значение |
| --- | --- |
| `--input` | Путь к исходному ZIP с `people.xml` либо к распакованному XML; по умолчанию `task_X1.zip` |
| `--output` | Путь к нормализованному XML |

По умолчанию `--output` равен `build/people.xml`. Повторный запуск перезаписывает выбранный результат.

## Стек

Java 21, JAXB Runtime 4.0.5, Jakarta XML Binding API 4.0.2, XML Schema 1.0 из JDK, Gradle Wrapper и JUnit Jupiter 5.9.1.

## Проверка

```bash
./gradlew check
```

Проверяются запись/чтение JAXB, восстановление IDREF как ссылок на те же объекты, регистрация ID в DOM и отказы схемы для неверного пола, повторного ID и отсутствующего адресата.
