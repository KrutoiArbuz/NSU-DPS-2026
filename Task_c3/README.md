# Task_c3

Параллельный filter обрабатывает блоки входной последовательности через futures и сохраняет порядок результата.

## Функциональность

- Поддерживает конечный и бесконечный вход.
- Каждый future обрабатывает целый блок.
- Настраиваются размер блока и число одновременно запущенных задач.
- Обычный вызов `parallel-filter` использует блок 64 и четыре задачи.

## Запуск

Нужна Java 21. Команды выполняются из папки `Task_c3`. При первом запуске Gradle скачает зависимости.

```bash
./gradlew run
```

Программа измеряет время обычного и параллельного `filter` и проверяет равенство результатов.

## Стек

Clojure 1.12.0 на Java 21; самостоятельный проект со своим Gradle Wrapper, тесты через `clojure.test`.

## Проверка

```bash
./gradlew check
```

Проверяются порядок, неполный последний блок, бесконечный вход, отложенное начало и ограниченное опережение. Отдельный тест с CountDownLatch доказывает одновременную работу двух блоков.
